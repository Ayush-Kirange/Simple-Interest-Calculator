# Simple Interest Calculator

## About the Project
This project is a simple interest calculator that calculates the interest earned on a principal amount based on the annual rate of interest and the time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Annual rate of interest
- Time period in years

## Output
The calculated simple interest.
